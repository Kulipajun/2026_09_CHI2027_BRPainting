# BR Painting — Interactive Supplementary Material

A static, GitHub Pages-ready collection of 32 interactive painting records from the Hongo and Kashiwa user-study sites.

## Preview locally

Serve this folder with any static HTTP server. For example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`. Opening `index.html` directly may be restricted by browser iframe security.

## Deploy to GitHub Pages

1. Push the repository to GitHub.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch and `/ (root)`, then save.

The site uses only relative paths and requires no build step.
